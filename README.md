# Resolver360 Final Frontend

Plain HTML, CSS and JavaScript prototype for the Resolver360 Digital Workplace Resolution System.

## Included
- Landing page
- Login, Sign Up and Forgot Password
- Mock authentication using localStorage/sessionStorage
- Employee dashboard
- HR dashboard
- Admin dashboard
- Role-based navigation and mock data for every dashboard section
- Issue reporting, live status, past history, ratings & feedback, and profile
- HR analytics and employee impact
- Admin SLA monitoring, performance and analytics
- Collapsible hamburger sidebar
- Light/dark theme
- Password reset for mock accounts and registered users

Open `index.html` in a browser, or use VS Code Live Server for the best local experience.
